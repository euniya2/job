오늘은 크롬 웹에서만 진행합니다. 앱은 설치하지 않습니다.

노션 열기notion.com Gemini 열기gemini.google.com · 노션과 같은 구글 계정
양식이나 내용을 만들기 어려울 때 AI에게 요청합니다.
프롬프트의 노란 칸은 눌러서 내 내용으로 바꾼 뒤 복사합니다.
1

가입 순서

  1. notion.com 접속 → 오른쪽 위 'Notion 무료로 사용하기'

  4. 추가 질문 · 팀원 초대 · 앱 설치 안내는 모두 '건너뛰기'

노션 첫걸음 — 나만의 첫 페이지

빈 줄에서 / 를 치면 블록 메뉴가 열립니다. 이것 하나만 기억하면 됩니다.

1

자주 쓰는 블록

입력만들어지는 블록업무에서 이렇게
/제목1 /제목2큰 제목 · 중간 제목보고서 장 제목, 구역 나누기
/할일체크박스행사 준비 체크리스트
/토글접었다 펴는 목록참고 자료 · 긴 메모 숨기기
/콜아웃아이콘이 붙은 강조 상자마감일 · 주의 사항 강조
/구분선가로줄내용 구역 나누기
/페이지하위 페이지페이지 안에 페이지 넣기
블록 왼쪽에 마우스를 대면 손잡이(점 여섯 개)가 나타납니다. 잡고 끌면 이동, 다른 블록 옆에 놓으면 2단이 됩니다. 한 블록 안에서 줄만 바꾸려면 Shift + Enter.
2

실습 — 나만의 첫 페이지 만들기

제목과 내용은 각자 업무로 바꿔도 됩니다.

  1. 사이드바 '+' → 새 페이지 → 제목 예 : 10월 행사 준비 → 아이콘 추가
  2. /제목2 '할 일' → /할일 3개 입력
  3. /콜아웃 '마감 10.31' → /토글 '참고 자료'
  4. 블록을 옆으로 끌어 2단 만들기 → 손잡이 클릭 → '색'으로 강조
  5. /페이지 로 하위 페이지 하나 넣고, 상단 경로를 눌러 돌아오기

나의 업무 대시보드

데이터베이스는 행 = 업무 하나(페이지), 열 = 속성인 '관리하는 표'입니다.

1

대시보드 윗부분 만들기

01에서 배운 블록을 다시 써 봅니다. 할 일 네 개는 오늘 네 구간이라, 구간이 끝날 때마다 체크합니다.

  1. 새 페이지 → 제목 나의 업무 대시보드
  2. /콜아웃 → 이번 주 목표 : 업무 자동화 하기
  3. 'To-Do List' 한 줄 → /할일 4개 : 노션 기초 기능 사용 · 업무 대시보드 만들기 · 자동화 구성하기 · 폼 연결하기
  4. 할 일 두 개를 옆으로 끌어 2단으로 배치합니다
  5. /토글 생성형 AI 리스트 → 안에 Gemini · ChatGPT · Claude 링크
시간이 남으면 아이콘 · 커버를 넣어 꾸밉니다.
2

데이터베이스 만들기

  2. 데이터베이스 제목을 업무관리 로 바꿉니다
  3. 열 머리글을 눌러 이름 · 유형을 아래 표처럼 맞춥니다. 오른쪽 끝 '+' 로 열을 추가합니다
속성 이름유형설정

상태상태시작 전 · 진행 중 · 완료 (기본값 그대로)
마감일날짜—

담당자사람나를 선택
'상태'는 반드시 상태 유형으로 만듭니다. '선택' 유형으로 만들면 03 구간의 완료 버튼이 동작하지 않습니다.

AI 업무 목록 요청 — 내 업무 4~5건 받기

주간업무 보고서 아래에 내 업무를 채웁니다. 이후 보드 · 캘린더 · 필터 실습이 모두 내 업무로 진행됩니다.

Gemini에 붙여 넣기 · ✏️ 두 곳을 바꿉니다
나는 [✏️ 경영기획 / 문화예술경영] 업무를 하는 직원이야.
이번 달 내 업무를 노션 업무관리 표에 정리하려고 해.
요즘 하는 일 : [✏️ 예) 11월 지역 축제 준비, 분기 예산 보고]
업무 4~5개를 아래 형식의 표로 만들어 줘.
- 열 : 업무명 / 상태 / 마감일 / 우선순위
- 상태 : 시작 전 · 진행 중 · 완료 중 하나
- 우선순위 : 높음 · 보통 · 낮음 중 하나
- 마감일 : 10월 20일 ~ 11월 7일 사이로 골고루
- 내가 추가한 열 : [✏️ 없음]
  1. 업무관리 표에 속성을 더 만들었다면, '내가 추가한 열' 노란 칸에 그 속성 이름을 적습니다. 없으면 그대로 둡니다
  2. 결과에 업무명 · 상태 · 마감일 · 우선순위(+ 추가한 열)가 다 있는지 봅니다
  3. 주간업무 보고서 행은 남겨 두고, 받은 업무를 그 아래 행에 입력합니다
  4. 다듬기 예 : "우선순위 높음은 2개로 줄여 줘"
Gemini 표를 통째로 노션에 붙이지 않습니다. 일반 표가 되거나 상태 · 날짜 유형이 깨집니다. 업무명은 붙여 넣고, 상태 · 우선순위는 고르고, 마감일은 날짜로 입력합니다.
4

실습 — 원하는 방식으로 보기

보기를 몇 개 만들어도 데이터는 하나입니다. 보드에서 카드를 옮기면 표의 상태도 바뀝니다.

보기 이름만드는 법설정
진행 보드보기 탭 '+' → 보드그룹화 기준 : 상태 → 카드 하나를 '진행 중'으로 끌어 옮기기
마감 달력보기 탭 '+' → 캘린더날짜 기준 : 마감일
급한 일보기 탭 '+' → 표필터 : 우선순위 = 높음 / 정렬 : 마감일 오름차순
필터 · 정렬 아이콘은 데이터베이스 오른쪽 위에 있습니다. 창이 좁으면 ⋯ 안에 숨어 있으니 브라우저를 최대화합니다.

03

버튼 자동화

자동화 = 언제(트리거) + 무엇을(액션). 노션 무료 플랜에서는 '버튼을 누르면'이 트리거입니다.

1

버튼 블록 — 누르면 주간보고 양식이 생깁니다

  1. 대시보드 페이지 빈 줄에 /버튼
  2. 버튼 이름 : 주간보고 생성1
  3. 작업 추가 → 블록 삽입
  4. 아래 양식을 복사해 설정 창 안의 편집 칸에 붙여 넣습니다
  5. 날짜 줄에는 @오늘 을 직접 입력합니다 → 완료
  6. 버튼을 두 번 눌러 양식이 생기는지 확인합니다
주간보고 양식 · 내 업무 양식으로 바꿔도 됩니다
#### 📌 주간보고
@오늘

#### 이번 주 성과
- 리스트

#### 다음 주 계획
- 리스트

#### 이슈
- 리스트
붙여 넣은 뒤 '@오늘'이 글자로 남아 있으면 지우고 직접 @오늘을 입력해 날짜 표시로 바꿉니다. 제목 · 목록 모양이 다르게 붙으면 손잡이 → '전환'으로 다듬습니다.
버튼을 고치려면 버튼에 마우스를 올리고 오른쪽 톱니바퀴(설정)를 누릅니다.
2

데이터베이스 템플릿 + 버튼 — 업무관리 표에 주간보고서 행 추가

1번 버튼은 '페이지 안에' 양식을 만들고, 이번 버튼은 '업무관리 표에' 새 행을 만들면서 서식을 넣습니다.

  1. 업무관리 표 오른쪽 위 '새로 만들기' 옆 ▼ → 새 템플릿
  2. 템플릿 제목 주간보고서 → 속성(상태 · 우선순위 · 담당자) 기본값 입력 → 본문에 주간보고 양식 작성
  3. 대시보드 페이지에 /버튼 → 이름 주간보고 생성2
  4. 작업 추가 → 페이지 추가 위치 → 데이터 소스 업무관리 선택 → 템플릿 주간보고서 선택 → 완료
  5. 버튼을 누르고 업무관리 표에 새 행이 생겼는지 확인합니다
3

버튼 속성 — 누르면 업무가 '완료'로 바뀝니다

버튼 블록은 페이지에 하나, 버튼 속성은 표의 행마다 하나씩 붙습니다.

  1. 업무관리 표에 날짜 속성 추가 → 이름 완료날짜
  2. '+' → 유형 버튼 → 이름 완료버튼
  3. 속성 메뉴 → 자동화 편집
  4. 작업 : 이 페이지 편집 → 상태 = 완료 / 완료날짜 = 버튼을 누른 날짜 → 저장
  5. 행의 버튼을 누르고, 진행 보드에서 카드가 '완료' 열로 옮겨졌는지 확인합니다
대상을 '이 페이지'로 하지 않으면 다른 행이 바뀝니다. 상태 값이 보이지 않으면 '상태' 속성이 '선택' 유형으로 만들어진 것입니다.

업무지원 요청 접수 폼

노션 폼은 데이터베이스에 붙은 설문지입니다. 폼을 만들면 응답이 쌓일 표가 함께 생깁니다. 표를 따로 만들 필요가 없습니다.

1

폼 만들기

  1. 새 페이지 → 제목 업무지원 접수
  2. 본문에서 /폼 → 폼 선택
  3. 폼 제목 : 업무지원요청서
  4. 아래 표대로 질문 네 개를 만들고, 필요한 질문은 필수를 켭니다
질문유형설정
이름제목필수 · 텍스트가 아니라 제목 유형으로 바꿉니다
요청내용텍스트필수
업무중요도객관식옵션 : 높음 · 보통 · 낮음 / 최대 선택 항목 수 1
마감일날짜—
폼 위쪽의 양식 작성기는 질문을 만드는 곳, 응답은 응답이 쌓이는 표입니다. 질문 하나가 표의 열 하나가 됩니다. 응답자 · 제출 시간 열은 노션이 자동으로 붙입니다(로그인 없이 응답하면 응답자는 빈칸). 필요 없으면 열 머리글 → 보기에서 숨기기.
2

폼 공유하고 외부 사람처럼 응답하기

  1. 폼 오른쪽 위 파란 양식 공유
  2. 작성 가능한 사용자 : 링크가 있는 모든 사용자
  3. 폼 링크 복사
  4. Ctrl + Shift + N 으로 시크릿 창 → 링크 붙여 넣기 → 응답 제출
  5. 원래 창의 응답 탭에 새 행이 생겼는지 확인합니다
주소창의 페이지 주소를 보내면 '접근 권한 요청'이 뜹니다. 반드시 양식 공유에서 복사한 링크를 씁니다. 평소 창에서 폼이 계속 로딩되면 새로고침을 몇 번 하거나 시크릿 창으로 엽니다.
